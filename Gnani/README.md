# Gnani AI Hackathon Integration (Aether Navigator)

This folder and the corresponding `Backend/gnani/` module provide full multilingual voice capabilities for the Aether Browser Assistant using **Gnani.ai** models:

1. **Gnani Prisma (Speech-to-Text / ASR)**:
   - Captures live user speech in any language (Hindi, Tamil, Telugu, Kannada, Bengali, Marathi, Gujarati, English, Hinglish, etc.).
   - Transcribes audio into text and automatically detects the spoken language code (`Auto-LID`).

2. **Gnani Evon 3.3 (Task Converter & Multilingual NLU)**:
   - Takes the native transcript and converts it into a concise, actionable browser automation instruction in English.
   - Saves the user's spoken language for the return response.

3. **DeepSeek Agent (Browser Automation)**:
   - Takes the English task generated by Evon 3.3 and automates the browser via CDP (`agent-browser`).
   - Streams real-time tool execution (`snapshot`, `navigate`, `interact`, `click`, etc.) to the assistant panel.
   - Formulates the final execution summary in English.

4. **Gnani Evon 3.3 + Timber 2.5 (Multilingual TTS Response)**:
   - Evon 3.3 translates DeepSeek's final English summary back into the user's original spoken language.
   - Timber 2.5 synthesizes high-quality, expressive speech in that language.
   - Automatically plays the voice back to the user on the assistant panel, with a replay button.

## Architecture & File Locations

### Backend Module:
`f:\Browser Development\Agentic AI\aether-navigator\Backend\gnani\`
- `__init__.py`: Module entry point with `ENABLE_GNANI` flag.
- `config.py`: Gnani API keys, base URLs, and model configurations (`prisma-v3.0`, `gnani-evon-v3.3`, `timbre-v2.5`).
- `prisma_stt.py`: Prisma Speech-to-Text client.
- `evon_llm.py`: Evon 3.3 task formulator and translator.
- `timber_tts.py`: Timber 2.5 Text-to-Speech synthesizer.
- `routes.py`: FastAPI endpoints (`/gnani/status`, `/gnani/transcribe`, `/gnani/tts`, `/gnani/voice-chat`).

### Frontend Components:
`f:\Browser Development\Agentic AI\aether-navigator\frontend\src\components\gnani\`
- `SpeakButton.tsx`: Animated microphone button with listening pulse & volume visualizer.
- `AudioPlayer.tsx`: Audio playback widget for Timber 2.5 responses.
- `useVoiceRecorder.ts`: Microphone stream and audio recording hook.

## How to Configure API Keys

In `Backend/.env`, set:
```dotenv
GNANI_API_KEY = "vach_your_gnani_api_key_here"
```
*(Optional custom endpoints and models can also be overridden in `Backend/gnani/config.py`)*

---

## How to Remove or Disable this Integration (Modular Decoupling)

If you ever want to completely remove or disable the Gnani AI integration:

1. **Disable in Backend**:
   In `Backend/app.py`, comment out the router registration:
   ```python
   # app.include_router(gnani_router)
   ```
2. **Disable in Frontend**:
   In `frontend/src/components/InputBar.tsx`, remove or omit `<SpeakButton />`.
3. **Delete the folders** if desired:
   - `Backend/gnani/`
   - `frontend/src/components/gnani/`

The core DeepSeek browser automation and normal text chat will continue to function 100% normally without any dependency on Gnani.
